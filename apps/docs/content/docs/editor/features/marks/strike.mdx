title: Strike
description: Strikethrough text with `toggleStrike`.
---



Type: **Mark**

Strike draws a line through text to indicate deletion. Renders as `<s>` in HTML output.

## Commands

```ts
editor.runCommand("toggleStrike");
```

## Keyboard Shortcut

**Mod + Shift + S**

## Active State

```ts
const isActive = editor.isActive("strike");
```
