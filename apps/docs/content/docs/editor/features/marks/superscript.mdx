---
title: Superscript
description: Make text superscript with `toggleSuperscript`.
---



Type: **Mark**

Superscript renders text smaller and above the baseline. Useful for footnotes and mathematical exponents.

## Commands

```ts
editor.runCommand("toggleSuperscript");
```

## Active State

```ts
const isActive = editor.isActive("superscript");
```
