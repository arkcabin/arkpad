---
title: Underline
description: Underline text with `toggleUnderline`.
---



Type: **Mark**

Underline adds a line below text. Renders as `<u>` in HTML output.

## Commands

```ts
editor.runCommand("toggleUnderline");
```

## Keyboard Shortcut

**Mod + U**

## Active State

```ts
const isActive = editor.isActive("underline");
```
