---
title: Subscript
description: Make text subscript with `toggleSubscript`.
---



Type: **Mark**

Subscript renders text smaller and below the baseline. Useful for chemical formulas.

## Commands

```ts
editor.runCommand("toggleSubscript");
```

## Active State

```ts
const isActive = editor.isActive("subscript");
```
