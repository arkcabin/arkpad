---
title: Color
description: Change text color in the editor.
---

Type: **Mark** · Category: **Style**

Color allows users to apply custom text colors to selected content.

## Commands

```ts
editor.runCommand("setColor", "#ff0000"); // Red text
editor.runCommand("unsetColor"); // Remove color
```

## Configuration

```ts
Color.configure({
  colors: ["#000000", "#ff0000", "#00ff00", "#0000ff"],
});
```
