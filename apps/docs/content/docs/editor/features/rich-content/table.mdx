Type: **Node**

Table inserts a grid of rows and columns for structured data. Supports column resizing, cell merging, and header rows.

## Commands

```ts
editor.runCommand("insertTable", { rows: 3, cols: 3 });
```

## Table Management Commands

| Command           | Description             |
| :---------------- | :---------------------- |
| `addColumnBefore` | Add column to the left  |
| `addColumnAfter`  | Add column to the right |
| `deleteColumn`    | Delete selected column  |
| `addRowBefore`    | Add row above           |
| `addRowAfter`     | Add row below           |
| `deleteRow`       | Delete selected row     |
| `mergeCells`      | Merge selected cells    |
| `splitCell`       | Split merged cell       |
| `deleteTable`     | Remove entire table     |

## Active State

```ts
const isActive = editor.isActive("table");
```

## Configuration

```ts
Table.configure({
  resizable: true, // Enable column resizing
  handleWidth: 5, // Resize handle width (px)
  cellMinWidth: 25, // Minimum cell width (px)
});
```

## Markdown Shortcut

Type `|||` followed by space for a 3-column table.
